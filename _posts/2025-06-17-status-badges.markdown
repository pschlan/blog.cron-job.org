You can now use cron-job.org status badges to embed the latest status of your job into your custom web sites, dashboards, READMEs, markdown documents etc.

To use the new feature, edit the cron job in our [Console](https://console.cron-job.org){:target="_blank"} and click "Actions" and "Status badge". You can select which information to include in the badge and copy the badge URL and/or markdown code for it.

![Example of retrieving a status badge for a job](/assets/2025/06/status-badge-ui.png)

As usual, if you have any feedback or suggestions for us, please let us know at [info@cron-job.org](mailto:info@cron-job.org).
